How the rewrite works — and what to review

A curated English lexicon and grammatical rules choose eligible substitutions, preserve inflections, and adjust a/an. Simple clause and manner-adverb moves offer structural variation. Ambiguous scopes, quotations, URLs, email addresses, and backtick code are protected.

This is not a language model or a guarantee of equivalent meaning. Idioms, technical senses, register, and emphasis can still shift. Check every change before using the result. Broader vocabulary is more likely to shift nuance; uncheck sentence moves for a more conservative pass.

Import UTF-8 .txt or .md files up to 1 MiB. The browser normalises textarea line endings to LF. The native CLI keeps line endings and has no imposed document-size limit beyond available memory. Text is not saved between page visits.
